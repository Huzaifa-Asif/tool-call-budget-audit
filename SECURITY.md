# Security policy

## Supported version

The latest released major version receives security fixes.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories for `Huzaifa-Asif/tool-call-budget-audit`. Do not open public issues containing credentials, tool arguments, sensitive identifiers, or exploit details.

The package accepts metadata only and does not make a tool call safe or authorized. Callers remain responsible for schema validation, permission checks, idempotency, and side-effect controls.
